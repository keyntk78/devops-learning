# Module 3: Networking

## Mục tiêu

- Hiểu request đi từ máy người dùng đến service như thế nào.
- Nắm IP, port, DNS, TCP, UDP, HTTP, TLS, proxy và load balancer.
- Biết dùng công cụ debug networking cơ bản.

## Chủ đề chính

- IP address, subnet, gateway, NAT
- Port, socket, TCP handshake
- DNS record: A, AAAA, CNAME, MX, TXT
- HTTP request/response, status code, header
- TLS certificate và HTTPS
- Proxy, reverse proxy, load balancing
- Debug tools: `ping`, `tracert`, `nslookup`, `curl`, `netstat`, `Test-NetConnection`

## Lab gợi ý

Chọn một website bất kỳ và ghi lại:

- Domain resolve ra IP nào
- HTTP status code trả về
- Header quan trọng
- TLS certificate thuộc về ai

## Câu hỏi ôn tập

- DNS làm gì trong request flow?
- Load balancer khác reverse proxy thế nào?
- Vì sao service cần health check?
- HTTP `502`, `503`, `504` thường gợi ý lỗi gì?
