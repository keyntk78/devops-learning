# Module 4: Git Collaboration

## Mục tiêu

- Làm việc với Git theo workflow nhóm.
- Hiểu branch, commit, merge, rebase, tag và release.
- Biết xử lý conflict và viết commit message dễ đọc.

## Chủ đề chính

- Working tree, staging area, commit history
- Branch strategy: trunk-based, Git Flow, feature branch
- Pull request và code review
- Merge conflict
- Tag, release, changelog
- Conventional commits

## Lab gợi ý

Tạo một repo nhỏ và thực hành:

- Tạo branch feature
- Commit thay đổi
- Merge vào main
- Tạo tag release
- Viết changelog ngắn

## Câu hỏi ôn tập

- Khi nào nên rebase, khi nào nên merge?
- Pull request giúp giảm rủi ro gì?
- Tag khác branch thế nào?
- Commit message tốt cần nói điều gì?
