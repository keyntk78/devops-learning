# Module 12: SRE và Operations

## Mục tiêu

- Vận hành service theo mục tiêu độ tin cậy.
- Hiểu SLI, SLO, error budget, incident response và postmortem.
- Viết runbook để xử lý sự cố lặp lại.

## Chủ đề chính

- Reliability và availability
- SLI, SLO, SLA
- Error budget
- Incident lifecycle
- Runbook và playbook
- Postmortem không đổ lỗi
- Capacity planning
- Disaster recovery: RTO, RPO

## Lab gợi ý

Viết runbook cho tình huống API trả nhiều lỗi `5xx`:

- Dấu hiệu nhận biết
- Dashboard cần xem
- Lệnh kiểm tra
- Cách giảm ảnh hưởng
- Cách rollback
- Khi nào escalation

## Câu hỏi ôn tập

- SLI khác SLO thế nào?
- Error budget giúp ra quyết định release ra sao?
- Postmortem tốt cần tránh điều gì?
- RTO và RPO khác nhau thế nào?
