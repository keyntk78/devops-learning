# Module 7: Cloud

## Mục tiêu

- Hiểu các thành phần cloud cơ bản để đọc được kiến trúc hệ thống.
- Nắm compute, storage, network, IAM, database và managed services.
- Biết tư duy cost, security và reliability khi dùng cloud.

## Chủ đề chính

- Region, availability zone
- IAM: user, role, policy, least privilege
- Compute: VM, container service, serverless
- Storage: object, block, file
- Network: VPC/VNet, subnet, route table, security group/firewall
- Database managed services
- Backup, cost tag, quota

## Lab gợi ý

Thiết kế kiến trúc cloud cho web app 3 tầng:

- Frontend
- Backend API
- Database
- Object storage
- Logging/monitoring

Ghi rõ boundary bảo mật và đường đi request.

## Câu hỏi ôn tập

- IAM role khác IAM user thế nào?
- Object storage phù hợp cho loại dữ liệu nào?
- Vì sao nên tách public subnet và private subnet?
- Managed database giúp giảm việc vận hành nào?
