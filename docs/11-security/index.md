# Module 11: Security

## Mục tiêu

- Tích hợp bảo mật vào quy trình DevOps.
- Quản lý secrets an toàn.
- Giảm rủi ro từ image, dependency, permission và supply chain.

## Chủ đề chính

- Least privilege
- Secrets management
- Dependency scanning
- Container image scanning
- SBOM cơ bản
- Network policy và firewall
- TLS và certificate rotation
- Audit logs

## Lab gợi ý

Thực hiện security review cho một app container:

- Kiểm tra secret có bị commit không
- Scan dependency
- Scan image
- Kiểm tra user trong container
- Kiểm tra port expose
- Ghi các rủi ro và cách giảm thiểu

## Câu hỏi ôn tập

- Vì sao secret trong Git rất nguy hiểm?
- Least privilege áp dụng vào CI/CD như thế nào?
- Image base quá cũ có rủi ro gì?
- Audit log cần trả lời được câu hỏi nào?
