# DevOps Wiki

Đây là không gian ghi chép khóa học DevOps theo kiểu wiki. Mục tiêu là vừa học có hệ thống, vừa để agent có thể đọc lại ngữ cảnh và giúp bạn mở rộng ghi chú qua từng buổi.

## Cách dùng nhanh

1. Bắt đầu tại [docs/index.md](docs/index.md).
2. Theo lộ trình trong [docs/00-khoi-dong/roadmap.md](docs/00-khoi-dong/roadmap.md).
3. Sau mỗi buổi học, cập nhật [docs/00-khoi-dong/progress.md](docs/00-khoi-dong/progress.md).
4. Khi ghi bài mới, dùng mẫu trong [docs/templates/note.md](docs/templates/note.md).
5. Khi làm thực hành, dùng mẫu trong [docs/templates/lab.md](docs/templates/lab.md).

## Chạy như wiki site

Khung này tương thích với MkDocs. Khi muốn xem dưới dạng website:

```powershell
pip install -r requirements.txt
mkdocs serve
```

Sau đó mở địa chỉ local mà MkDocs in ra.
